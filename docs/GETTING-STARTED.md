# 首次使用与排错

**简体中文** | [English](GETTING-STARTED.en.md)

## 安装并连接模型

从 Releases 下载 Windows x64 安装包。源码 ZIP 不能代替安装包。安装包不包含模拟器、游戏或模型账号。

按 [Codex CLI 官方说明](https://developers.openai.com/codex/cli/) 或 [Kimi Code 官方说明](https://www.kimi.com/code/docs/) 安装并认证 CLI，先确认它独立运行可以回答。Runtime 目前只适配这两个宿主，以 Codex CLI 为主；不能仅填写其他 Agent 的路径就使用。上游 CLI 协议升级可能需要适配更新。

在“宿主 Agent”中点击“扫描本机 CLI Agent”，选择目标，再“连接所选 Agent”。选择账号实际可用的模型与推理强度，普通策略任务可先用 low/medium。先在大厅测试完整回答。

**按场景选择速度：**日常大厅可以使用思考强度较高的模型深入讨论；Start Match 请优先使用响应较快的模型，推理强度以能及时返回建议为准。不要直接沿用大厅的高思考强度设置，先测试实际速度，避免错过强化等限时选择。

## MuMu：确认 ADB，并开启阵容大师

1. 打开 MuMu，启动金铲铲游戏。
2. 确认 ADB 调试状态：模拟器右上角“…”菜单 →“设备设置”→“开发者选项”→“ADB 调试”。在本指南所示版本中默认是“开启本地连接”，已经是该状态就无需修改；若被关闭，再改为“开启本地连接”。不同版本菜单位置可能不同，不要照抄其他电脑的端口。
3. 游戏窗口右上角打开“工具箱”，进入“金铲铲之战工具箱”，开启“金铲铲阵容大师”。按当前产品实测，这是完整棋盘与商店棋子信息的必要条件。
4. 在 Runtime 中打开“连接 MuMu”，点击“一键识别 MuMu / ADB 端口”，连接正在运行游戏的实例。

仅 ADB 连通不代表所有信息就绪。缺棋盘/商店时先检查阵容大师；缺阶段、血量等信息时检查监听与 HUD/OCR 状态。当前完整实时链路以 MuMu 为支持环境；大厅不依赖 MuMu。

## Start Match 与手动记录

进入游戏后点击 Start Match，建立本局会话并开始监听，确认阶段与局面信息更新。巡航只在已注册的战略检查点触发，不是每次刷新商店都会回答；仍可随时主动提问。

在对应卡片内保存/确认强化、装备与转职信息，不要只填字但不提交。OCR 或观战视角可能缺信息，需要时手动补充。“已接入”不是所有字段都已识别。阵容图是建议展示，不自动操控游戏。

结束一局后停止对局，再开始下一局。“开启新对话”用于大厅，是另一条会话边界。

## 数据更新、升级、卸载

“更新今日数据”需要联网，语义维护还需要可用模型宿主。等待流程完成并检查统计日期；来源未更新时不能将日期伪装成今天。不要手工改活动数据指针。

**游戏小版本更新：**当前尚未加入游戏小版本适配的自动更新机制。维护者会在 GitHub 发布适配更新，请关注仓库及 Releases，按对应说明更新；“更新今日数据”只负责数据流水线，不代表自动完成版本适配或应用升级。

**新版本数据延迟：**根据维护者目前观察，大数据通常比游戏小版本更新延迟约 1 天，反映新环境的强度梯队通常延迟约 2–3 天。这是经验范围，不是固定承诺；以来源统计日期和实际发布情况为准。更新初期的梯队可能仍受旧版本样本影响，不能直接视作新版本最终强度。

新安装包使用原安装目录覆盖升级，正常保留用户数据。卸载默认保留数据，只有勾选“同时删除用户配置和运行数据”才清理应用自己的数据；静默卸载与升级默认保留。

用户数据默认在系统解析的 `%APPDATA%\jcc-runtime-ui`，其中 `runtime-data` 保存 Runtime 状态。系统重定向时实际路径可能不同，它不一定在安装文件夹内。不要删除 Codex/Kimi 的认证目录或模拟器目录来清理 Runtime。

## 排错

| 现象 | 检查 |
| --- | --- |
| 扫描不到 CLI | CLI 是否已安装、能否独立运行；重启 Runtime 后重扫 |
| Provider 401/403/404/429 | 认证、权限、模型映射、服务状态或额度 |
| MuMu 自动发现失败 | 实例是否运行、ADB 是否启用、是否选对实例与端口 |
| 已连接但无棋盘/商店 | 工具箱中的金铲铲阵容大师是否开启 |
| HUD 未就绪 | 游戏视角、HUD/OCR 状态；与 ADB 连通分别检查 |
| 主动问答正常但巡航没有 | 阶段是否更新、是否到检查点、任务是否完成并交付 |
| daemon exited before ready | 保存完整启动错误、版本、安装路径，不只报 code 1 |

反馈请附复现步骤和脱敏诊断，不公开上传认证文件、私人聊天、数据库或完整 Provider 日志。
